# N2CIAS by TenangAI: art prompt pack

Painted scenes to replace the hand-drawn SVG pieces. Every image uses the same **style block** and **palette**, so the set looks like one illustrator made it. Generate stills first; then make short loops from the stills for the hero and night scene (see "Motion" at the end).

## How to use

1. Paste the **style block**, then the scene prompt, then the **negative prompt** (or put it in the negative field if your tool has one).
2. Keep the same seed / style reference across the set once you like the first image.
3. Export at the size listed, as WebP (or PNG with transparency where marked), and save to `assets/art/` with the file name given. Send them over and I'll place them.
